Interactions

  • Brush: drag vertically on any axis; brushes on several axes combine (AND). Click an axis outside the brush to clear it.
  • Reorder: drag an axis title left or right.
  • Invert: double-click an axis title.
  • Bundle: raise β to pull lines of the same group towards the group centroid between axes; raise smoothness to curve them.
  • Hover a line for its values.

Brushed rows

Log axes (symmetric log, so zeros remain visible) are used for events, deaths, people affected, damage, deaths per event and growth. Damage is CPI-adjusted to 2022 US$; 0 means “not reported”. Data: EM-DAT country profiles (Kaggle, snapshot 2023-04-06).
